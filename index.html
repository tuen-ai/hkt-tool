      離線版使用說明

      這是 HKT tools · Seat Detail Report v1.0。開檔先見上傳頁，請自行選擇 .xlsx、.xls 或 UTF-8 .csv；冇示例資料。

      1. 選擇 Preset，檢查每個 Sheet 的配對提示。
      2. 在左邊選欄、篩選或排序；中間切換原始／輸出／變更預覽。下方值替換表已直接顯示，可即場改字，唔使開視窗。
      3. 按「核對並匯出 xlsx」會先建立檔案，再全量逐格核對。
      4. 核對通過後查看摘要，按「確認下載」。有不符可睇報告；勾選確認後仍可強制下載（檔名加 Verify_Failed）。

      「搜尋」及分頁只改畫面，唔影響匯出。藍底表示文字或欄名有改動；來源行號係原始 Excel 行號。核對報告涵蓋全部已勾選 Sheet，唔係只核對畫面顯示的行。

      Preset 另存於這個離線版專用的瀏覽器儲存空間；唔會讀取或改動原站的設定。檔案本身唔會存入瀏覽器儲存空間。file:// 的儲存支援視瀏覽器而定，建議用「匯出」備份 Preset。

      CSV 匯出不經逐格核對。Excel 輸出使用原版的讀寫及獨立核對核心；公式輸出為快取結果，無快取可能為空白，載入檢查會提示。

      本檔案已內置所需程式；處理檔案全在本機，唔會上傳你嘅 Excel。開啟頁面時會向正式版同一個計數器回報使用次數（abacus）。可維護原始碼及麥座線上書籤工具不包括在此 review 版。

      另存 Preset

      包括全部 Sheet 的選欄、篩選、排序及替換表。不包括檔案資料或人手剔除行。
