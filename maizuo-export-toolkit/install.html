麥座導出工具包

同一個安裝頁，兩個書籤——正式單匯出（Project 1）＋座位報表導出工具。請喺已登入 maizuo.imaitix.com 使用；更新時請覆蓋舊書籤。

點解改咗裝法：舊版把成段腳本塞入書籤 URL（十多萬字元），Chrome 拖去書籤列會靜默失敗／裝唔到。而家書籤只係短 loader，撳嘅時候先由 GitHub Pages 載入最新 .js（要能上網）。

  1. 顯示書籤列（Chrome：Ctrl+Shift+B / Mac Cmd+Shift+B）
  2. 將下面藍色掣拖入書籤列（或撳「複製書籤碼」→書籤管理→新增／編輯網址貼上）
  3. 去已登入嘅 maizuo.imaitix.com 撳書籤使用

書籤 A · 正式單匯出

關閉／正式單列表匯出 Excel；可選「計算票數」逐頁加總票張。亦支援項目清單操作同新分頁開啟。

正式單匯出

若拖曳失敗：複製上面書籤碼 → 書籤列右鍵「新增書籤」→ 網址貼上。

備用：Console 貼上（書籤仍唔得／CSP 擋外部腳本時）

喺麥座頁開 DevTools → Console → 貼上 → Enter。

書籤 B · 座位報表導出工具

座位／BI＋PMS 場次關鍵字篩選、時段過濾；座位信息 xlsx／座位狀態 PDF 自動下載「点击下载」。

座位報表導出工具

若拖曳失敗：複製上面書籤碼 → 書籤列右鍵「新增書籤」→ 網址貼上。

備用：Console 貼上（書籤仍唔得／CSP 擋外部腳本時）

喺麥座頁開 DevTools → Console → 貼上 → Enter。

必須喺 maizuo.imaitix.com 撳書籤（腳本會檢查網域）。Loader 會向 tuen-ai.github.io 拉最新碼，覆蓋舊書籤後先用到新功能。若公司網絡擋 GitHub，請用「複製 Console 版」。
